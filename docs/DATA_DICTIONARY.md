# Data Dictionary

| Field | Description |
|---|---|
| record_id | Synthetic observation identifier |
| product_id | Product/SKU identifier |
| category | Product category |
| our_price | Simulated selling price |
| competitor_price | Simulated competitor reference price |
| promotion | 1 when a promotion is active |
| day_of_week | Integer from 0 (Monday) to 6 (Sunday) |
| units_sold | Simulated units sold |

All included records are synthetic and contain no real retailer or competitor data.
